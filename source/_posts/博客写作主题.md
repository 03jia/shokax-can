函数中能否定义异步函数

对象或者类中定义异步函数

在对象字面量中，我们可以使用更简洁的方法简写语法。以下两种写法是等价的：

```typescript
// 方式1：完整语法
const service = {
  async function createArticle() {  // ❌ 语法错误
    // ...
  }
};

// 方式2：方法简写语法（推荐）
const service = {
  async createArticle() {  // ✅ 正确
    // ...
  }
};
```

这是因为：
1. 在对象字面量中，`function` 关键字是不必要的，可以直接使用方法简写语法
2. JavaScript/TypeScript 的对象方法定义有特殊的简写规则
3. `async` 可以直接和方法名结合使用，不需要 `function` 关键字

如果你非要用完整语法，需要这样写：
```typescript
const service = {
  createArticle: async function() {  // ✅ 也正确，但不推荐
    // ...
  }
};
```

但这种写法更冗长，所以通常我们都使用简写语法。
